# Python-Based Analysis of Cooling Curves in Medium-Carbon Steel

## About the Project

This project uses Python to simulate and analyze the cooling behaviour of medium-carbon steel under different cooling conditions.
In this i compares furnace cooling, air cooling, and water cooling using simulated temperature-time data and cooling-rate calculations.

## Objective

- To simulate cooling curves for medium-carbon steel.
- To compare furnace, air, and water cooling.
- To compare cooling rates.
- To understand how cooling rate can affect microstructure and mechanical properties.

## Results
- Furnace cooling: 2.04 °C/s
- Air cooling: 4.80 °C/s
- Water cooling: 14.95 °C/s

Water cooling has the highest cooling rate and furnace cooling has the lowest.


## Tools & Technologies
- Python
- NumPy

- Matplotlib

## Data Note

The data used in this project is simulated for learning purposes and is not experimental data.
